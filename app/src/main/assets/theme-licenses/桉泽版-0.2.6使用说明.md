# 同文云同步 0.2.6 桉泽版

直接覆盖安装 TrimeCloudSync-0.2.6-universal.apk，然后打开“同文·云同步”主页一次。沿用之前版本的包名和签名，不要先卸载或清除数据。词库、密钥、同步设置继续保留。

本次保留经典·顺手版布局，主空格键显示“桉 泽”；删除该键长按切换中英及“中/En”提示。中英切换仍可点顶部工具栏的“中/En”。空格左右滑动候选翻页保留。

A 上方的勾选框是全选快捷动作：向上或向下滑动 A 会全选当前输入框文本；长按弹出菜单中也有全选项。没有改成待办功能，没有删除全选动作。

## 底部红框

红框里的向下箭头、输入法切换按钮和底部横线是系统导航区域。本版将主题底部留白设为 0，并在首次升级开启同文已有的“忽略系统手势区域”选项，减少应用自行预留的空白。系统仍可能强制保留自己的区域，不能保证仅安装 APK 就能将整块红框隐藏。

请在手机系统设置中搜索“键盘位置”，如果有“默认/抬高”，选择“默认”；再找“快捷切换输入法”并关闭。若希望底部横线也隐藏，在系统导航/全面屏手势设置中查找手势提示条选项。具体名称和可用性取决于 ColorOS 版本。可参考一加社区的键盘位置入口：https://community.oneplus.com/thread/1197421312642383878 。这些是手机系统设置，APK 未连接手机，无法代替你操作。

如果取消留白后觉得空格键太靠下，可在同文“高级设置”关闭“忽略系统手势区域”。

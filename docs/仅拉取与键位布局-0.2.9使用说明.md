# TrimeCloudSync 0.2.9

版本名 `3.3.12-cloud0.2.9`，versionCode `20261020`（递增版本号，并非发布日期）。

## 仅拉取不上传

云同步页面新增“仅拉取不上传”复选框，默认勾选。新装及从旧版升级后均默认生效；用户手动改变后会保存设置。

勾选时，手动和每小时后台同步都只下载、校验、部署电脑方案，再把云端词库合并到手机。手机已有词库仍保留，原生同步产生的本机导出文件仅保存在手机；不会上传对象、发布 current.json 或删除云端对象。同步完成会显示“未上传或修改云端数据”。无需云端 ETag 即可拉取，双向上传仍必须有 ETag。

取消勾选会恢复此前的拉取、合并、上传流程。开启仅拉取后，已经启动的后台任务也会在下一次写请求前重新读取设置并停止后续写入；已经发出的请求无法撤回。每次以仅拉取启动的任务会全程保持只读，即使中途取消勾选也不会转为上传。

## 键位

从 QWERTY 起按参考图调整，原工具栏、配色和总键盘高度保持。默认中文、英文、万象、万象 Pro 四套字母布局一致调整：

- QWERTY 左右留边；ASDF 排居中错位，键间和行间留出间隔。
- 中文第三排为“分词 Z X C V B N M 退格”；英文对应位置保留 Shift。
- 底排依次为“符、123、逗号、桉 泽空格、句号、中/英、回车”。“符”和“123”各自独立。
- 数字提示和字母上的符号提示按参考图排列；长按 A 全选、X 剪切、C 复制、V 粘贴、Z 表情保留。空格左右滑动翻页，长按调用系统语音助手；语音是否可用取决于设备是否安装可响应的助手。

已导入的第三方自定义主题不会自动被覆盖；本次变更针对内置“经典·顺手版”。

## 构建和验证

原签名文件和 Android SDK 尚未迁移到本机。本次交付源码及补丁，不包含可覆盖旧版的正式 APK，也未发布 GitHub Release。请迁移原签名后按 `docs/DEVELOPMENT.md` 构建，发布标签使用 `v0.2.9`，四架构资产名使用 `TrimeCloudSync-0.2.9-universal.apk`。

独立测试（JDK 17 或更高版本）：

```powershell
javac -encoding UTF-8 -d work-tests app/src/main/java/com/osfans/trime/cloudsync/S3Client.java app/src/main/java/com/osfans/trime/cloudsync/SyncStorage.java cloud-sync-tests/PullOnlyTest.java cloud-sync-tests/StorageTest.java
java -cp work-tests PullOnlyTest
java -cp work-tests StorageTest
python -m pip install PyYAML
python cloud-sync-tests/keyboard_layout_test.py
```

完整 Android 键盘解析回归：

```powershell
.\gradlew.bat app:testDebugUnitTest --tests com.osfans.trime.data.theme.HanamaruTest
```

独立测试使用虚拟 HTTP 连接，不访问真实 S3 或用户词库。布局预览是根据 YAML 生成的示意图，不是真机截图；尚未进行安卓真机测试。

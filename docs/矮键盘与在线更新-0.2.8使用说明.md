# 0.2.8 矮键盘与 GitHub 更新

本版把主键盘总高度从 260dp 调整为 208dp，约缩短五分之一；横屏从 200dp 调整到 160dp。键间水平间隔由 2dp 缩为 1dp，竖向间隔由 4dp 缩为 3dp，字母字号由 24sp 调到 22sp。

第一排十个字母已占满屏幕，宽度无法凭空增加，主要减少间隙；第二排字母由 10% 加宽到 11%，第三排字母加宽到 10.5%。第二排两侧留白变小，第三排 Shift 和删除键稍收窄，各行总宽度保持 100%。空格、逗号、句号和回车的位置保留。是否减少误触仍需实际试用。

低面板下菜单在宽度足够时采用五列，否则保持四列并可滚动；底部导航区避让继续保留。

## 手机更新

0.2.7 没有应用内更新功能，因此这次需在手机浏览器打开 https://github.com/Anzaynt/TrimeCloudSync/releases/tag/v0.2.8 ，下载 APK 并覆盖安装一次，不必通过电脑传文件。不要先卸载或清除数据。

从 0.2.8 起，打开“同文·云同步”主页每天会自动检查一次正式 Release；随时可以点“检查 GitHub 新版本”。发现新版后，点下载，再确认安装。如果稍后安装，可点“安装已下载更新”。首次安装会要求到系统设置允许“同文·云同步”安装应用，返回后继续安装。

安卓系统仍需你确认安装，无法保证静默升级。检查不会在仅使用键盘时持续后台联网，也不会自动下载 APK。手机网络必须能访问 GitHub API 和 Release 下载域名；失败可以稍后手动重试。

下载时核对 GitHub 提供的 SHA-256，安装前核对包名、递增版本号及与旧版相同的签名证书。只保留一份待安装 APK，安装完成后下次进入主页会清理；中断下载的临时文件会清理。词库和 S3 设置不参与更新缓存清理。

开发者每次发布需上传 `TrimeCloudSync-X.Y.Z-universal.apk` 到同仓库正式 Release `vX.Y.Z`，递增 versionCode 并使用原私钥签名。未上传 APK、预发布版本和签名不同的包不会按正常更新安装。

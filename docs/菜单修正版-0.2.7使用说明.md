# 同文云同步 0.2.7 菜单修正版

覆盖安装 TrimeCloudSync-0.2.7-universal.apk，收起再打开键盘。若系统仍使用旧进程，重启手机。不需要卸载或清除数据。

菜单页原来每行固定 96dp，三行需要 288dp，超过当前 260dp 键盘面板。新版按菜单高度、项目数量和系统导航区计算行高，缩小按钮周围的空隙，并给菜单列表底部留出系统导航栏的安全空间。屏幕较小、字体较大或方案开关较多时，可上下滚动，最后一行能够滚到导航区上方。

修改限于菜单页的布局。保留“桉 泽”空格键、删除空格长按切换、中英工具栏、A 全选功能及现有同步功能。沿用上一版包名和签名。系统导航栏仍由手机设置控制。

验证包含菜单三行适配、较小视口、额外方案开关、主题解析、GitHub 压缩包安全检查、发布构建和签名。未连接一加 ACE 3 Pro，仍需手机确认系统导航区的最终显示。
